Campus alerts

Short messages at the top of a campus's dashboard. Up to three show at once, safety first. Publishing updates data/alerts.json on GitHub; the site shows the change within about two minutes.

1 Connect to GitHub

How to make a token (once)
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it "GradWay alerts" and pick an expiration (a year is fine).
  3. Under Repository access, choose Only select repositories and pick the site's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it, copy it and paste it above. It's sent only to GitHub.
